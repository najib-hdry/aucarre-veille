# Maquettes

Sources des planches de design (format Design Components `.dc.html`).

- `Main.dc.html` — écran d'accueil, maquette haute-fidélité (charte Au Carré : DM Sans + IBM Plex Mono, navy/crème/terracotta/teal).
- `canvas.json` — cadrage de la planche sur le canvas.

Canvas publié (aperçu + export PNG/PDF) :
https://claude.ai/code/artifact/ba25f5e4-325c-49cf-aa42-b963a654b188

Régénérer le canvas : via la skill `/design` de Claude Code (helper `seed-canvas.mjs`).
